Класифікація та аналіз оточення проєкту DormMate

5.1. Класифікація проєкту

Розмір проєкту
DormMate можна віднести до середніх проєктів. У ньому буде декілька основних функцій: авторизація, заявки на ремонт, оголошення, бронювання пральних машин, загублені та знайдені речі, опитування та особистий кабінет. Над проєктом працює команда з трьох людей

Тип продукту
DormMate — це вебзастосунок. Користувачі зможуть відкривати його через браузер без необхідності встановлювати окрему програму

Галузь застосування
Проєкт відноситься до сфери освіти, тому що він створюється для студентів, які проживають у гуртожитках навчальних закладів. Також системою зможуть користуватися працівники та адміністрація гуртожитку

Рівень невизначеності вимог
Рівень невизначеності вимог можна визначити як середній. Основні функції проєкту вже відомі, але під час роботи деякі деталі можуть змінюватися або доповнюватися

Модель співпраці
DormMate є внутрішнім продуктом. Проєкт виконується командою студентів у рамках навчання, окремого замовника у проєкту немає

Тип життєвого циклу
Для проєкту підходить гнучкий підхід Agile. Ми плануємо розробляти сайт поступово: спочатку зробити основні функції, а потім додавати інші можливості та виправляти помилки

5.2. Аналіз внутрішнього оточення

Склад команди
Команда DormMate складається з трьох людей. Неізвєстний Олексій — Team Lead, Мельничук Анастасія — Designer, Рябокінь Євгеній — Developer. Олексій допомагає організовувати роботу команди та бере участь у різних завданнях. Анастасія відповідає за дизайн, а Євгеній взаймається програмуванням

Досвід команди
Усі учасники команди мають студентський рівень

Технічні ресурси
Для роботи над DormMate ми використовуємо власні ноутбуки. Код плануємо писати у Visual Studio Code. Дизайн створюється у Figma. Для зберігання проєкту та спільної роботи використовується GitHub

Технології проєкту
Для frontend частини планується використовувати HTML, CSS, JavaScript та React. Для серверної частини планується використовувати Node.js та Express.js. Для роботи з версіями коду будемо використовувати Git та GitHub

Інструменти для комунікації
Для спілкування між учасниками команди використовуються Discord та Telegram

Часовий бюджет
На роботу над DormMate команда може виділяти приблизно 5–7 годин на тиждень. Через навчання часу не дуже багато, тому важливо правильно розподіляти завдання

Організаційне середовище
Проєкт виконується в рамках навчання в університеті. На роботу впливають дедлайни лабораторних робіт, інші предмети та загальне навчальне навантаження. Проєкт потрібно завершити до кінця семестру

5.3. Аналіз зовнішнього оточення

Цільова аудиторія
Основними користувачами DormMate будуть студенти, які проживають у гуртожитках. Також системою зможуть користуватися адміністрація, коменданти та інші працівники гуртожитку

Потреби користувачів
Студентам потрібне зручне місце, де можна переглядати оголошення, подавати заявки на ремонт, перевіряти їх статус, знаходити інформацію про загублені речі та брати участь в опитуваннях. Адміністрації буде зручніше переглядати звернення студентів та публікувати важливу інформацію

Аналог StarRez
StarRez — це система для роботи зі студентськими гуртожитками та проживанням студентів. Вона має багато різних функцій для студентів і працівників. DormMate має схожу загальну ідею, але наш проєкт буде простішим, тому що він навчальний

Аналог eRezLife
eRezLife — ще одна система для організації студентського проживання. Вона дозволяє організовувати комунікацію між студентами та адміністрацією. За своєю ідеєю вона частково схожа на DormMate

Технологічні тренди
Зараз багато сервісів переходять у вебформат. Користувачам зручно, коли всі функції знаходяться в одному місці. Також важливо, щоб сайт був простим, зрозумілим і нормально працював на різних пристроях

Правові фактори
У системі можуть використовуватися особисті дані користувачів, тому потрібно враховувати їх безпеку. Також звичайні користувачі не повинні мати доступу до адміністративних функцій

Зовнішні сервіси
На початковому етапі ми не плануємо сильно залежати від сторонніх сервісів або API. У майбутньому за необхідності можна буде додати різні повідомлення або сповіщення

5.4. Обмеження та припущення проєкту

Обмеження:
Проєкт потрібно завершити до кінця семестру
Команда може виділяти на роботу приблизно 5–7 годин на тиждень
У команді тільки три людини, і всі мають студентський рівень
Роботу над DormMate потрібно поєднувати з іншими навчальними предметами та завданнями

Припущення
Усі учасники команди будуть регулярно працювати над проєктом. Це потрібно для того, щоб встигнути завершити роботу до кінця семестру
Основні вимоги до проєкту сильно не зміняться. Якщо зміниться велика частина функцій, деяку роботу доведеться робити заново
Користувачі матимуть доступ до Інтернету та браузера. Це необхідно для використання вебзастосунку
Студентам буде зручніше користуватися одним сайтом, ніж вирішувати питання через різні чати та особисті звернення

5.5. Висновки
DormMate — це середній навчальний вебпроєкт. Оскільки деякі вимоги можуть змінюватися під час роботи, для нього підходить гнучкий підхід Agile. Це дозволить поступово робити окремі функції та при необхідності їх змінювати
Найбільше на роботу над проєктом впливають кількість людей у команді, наш досвід та обмежений час. У команді тільки три людини, а на проєкт ми можемо виділяти приблизно 5–7 годин на тиждень
Також важливо враховувати потреби майбутніх користувачів. Сайт повинен бути простим та зрозумілим як для студентів, так і для адміністрації гуртожитку
Серед основних ризиків можна виділити нестачу часу, складність деяких технічних завдань та можливі зміни вимог. Також нам може знадобитися додатковий час на вивчення React, Node.js та інших технологій
Далі команда планує більш детально розподілити завдання між учасниками та почати переносити готовий дизайн із Figma в код. Спочатку будуть реалізовані основні функції сайту, а потім поступово будуть додаватися інші можливості
